# Golden Set 第 4 组：宇智波佐助外传 · 残月之痕

## Prompt

请制作一个以《火影忍者》角色**宇智波佐助**为主角的原创外传故事网页。

核心定位

这不是角色百科、人物介绍页或动漫资讯页，而是一个具有完整剧情的**沉浸式视觉故事网页**。

故事发生在第四次忍界大战结束后的某段旅途中。佐助独自离开木叶，在忍界各地旅行，并调查战争结束后遗留下来的一系列异常事件。

请创作一个全新的原创外传故事，保持佐助冷静、克制、孤独但逐渐成熟的性格特点，同时不要直接复刻原作已有剧情或台词。

故事主题

核心主题可以围绕：**赎罪、孤独、过去与选择。**

故事中可以出现：

- 废弃的忍者村
- 神秘的宇智波遗迹
- 战争留下的秘密实验
- 写轮眼相关谜团
- 被战争改变的人
- 佐助对过去的反思

可以设计一个原创敌人或原创势力，让佐助逐渐发现事件背后的真相。

故事最后不要只是简单击败敌人，而是让佐助做出一个体现他成长的选择。

页面结构

页面至少包含：

1. **电影感首屏**
   - 大幅佐助视觉画面
   - 夜晚、月亮、荒野或废墟
   - 标题例如：**《宇智波佐助外传：残月之痕》**
   - 副标题：**战争结束了，但有些伤痕仍然留在黑暗之中。**
2. **故事序章**
   - 介绍佐助独自旅行的背景
   - 引出一个神秘任务或异常事件
3. **至少 6 个章节**
   - 每个章节都有独立场景和剧情推进，例如：
   - 第一章：消失的村庄
   - 第二章：雨夜中的写轮眼
   - 第三章：地下遗迹
   - 第四章：宇智波留下的秘密
   - 第五章：过去的亡灵
   - 第六章：残月之战
4. **关键人物**
   - 佐助
   - 1～3 个原创角色
   - 一个具有合理动机的主要敌人
5. **最终决战**
   - 设计具有视觉冲击力的战斗场景
   - 可以表现写轮眼、轮回眼、雷遁、须佐能乎等能力
   - 战斗应服务于剧情，而不是单纯技能展示
6. **故事结局**
   - 佐助解决事件后继续踏上旅途
   - 留下克制、有余韵的结尾

视觉风格

整体采用：**黑暗忍者世界 + 日式电影感 + 漫画分镜感**

推荐视觉元素：

- 黑色
- 深蓝
- 暗紫
- 月光白
- 少量宇智波红

加入：

- 月亮
- 乌鸦
- 雨
- 雷电
- 火焰
- 森林
- 废墟
- 宇智波团扇纹样
- 写轮眼元素

页面应该像一个可以滚动阅读的**动漫电影外传**。

不要大量使用普通圆角卡片。

可以使用：

- 全屏场景
- 大幅插画
- 漫画式分镜
- 图片与文字交错布局
- 大标题
- 黑屏转场
- 滚动触发文字出现
- 视差效果
- 战斗章节的动态视觉变化

不同章节要有明显的视觉节奏变化，避免整页都是“图片 + 一段文字”的重复结构。

最终效果

最终网页应该让用户感觉自己正在阅读一部真正的：**《宇智波佐助外传》互动视觉小说。**

重点是：**剧情完整、氛围浓厚、视觉高级、沉浸感强。**

不要制作成火影忍者百科、人物档案或简单动漫主题网站。

## Bad Reason

- 首屏和大多数章节主要依赖字体排版、CSS 图形与 SVG 装饰，实测页面没有场景图片，未充分兑现提示词对“大幅佐助视觉画面、全屏场景、大幅插画与漫画分镜”的明确要求。
- 首屏有强烈的海报感，但佐助本人没有成为主视觉中心
- Bad 版本长达七章加尾声，文字密度高，章节中多次回到“标题 + 长段正文 + 抽象装饰”的表达方式；视觉节奏更接近主题化长文，长距离滚动时容易产生阅读疲劳。
- 地下遗迹、人物与决战等关键段落主要通过符号化眼睛、线框、火焰和文字描述呈现，雷遁、写轮眼、轮回眼与须佐能乎缺少直接的场景画面支撑，战斗的视觉冲击力不足。
- 过多罗马音、日文副题、装饰性竖排文字和低对比度小字会与中文故事正文争夺注意力；部分实验性排版虽然有概念感，却牺牲了阅读流畅度。
