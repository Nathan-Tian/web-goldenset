# Web Golden Set

本仓库收集 22 个网页：10 对 Good / Bad 样本，以及 2 个独立参照页，用于比较相同任务下的页面交付质量。

## 主要观察

多数 Bad case 并不缺少文字内容，有些甚至比 Good case 更丰富。主要差距集中在主视觉质量、图文层级、排版、可读性与叙事节奏。

其中一个常见问题，是用简单的 SVG / CSS 几何图形承担人物、风景、艺术品或沉浸式场景，缺少必要的细节、材质和空间感。

SVG 适合 Logo、图标、数据图表和装饰线条，具有缩放清晰、便于修改和制作动画等优势。但粗糙的几何拼图往往难以胜任核心场景。高质量 SVG 同样可以表现出色，使用照片或生成图片也不保证页面设计优秀。

## 评估原则

- 减少对字数、章节数量和内容堆砌的奖励，提高设计表现的区分作用。
- 保留内容准确性、任务完成度与关键交互可用性的要求；图片本身也可能是核心内容。
- 结合 SVG 的用途、位置和实际效果判断，不按数量直接扣分。

## 资源与成本

本批 Good case 的资源体积通常更大，仍有图片压缩、字体精简和资源复用的优化空间。

文件大小不等于模型 token 消耗。生成成本需要结合实际用量日志单独评估，页面质量与资源成本应分别记录。
