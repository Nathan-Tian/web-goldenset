# Golden Set 第 6 组：人类首次登陆火星

## Prompt

请制作一个以 **“人类首次登陆火星”** 为主题的太空探索单页网站。

网站需要讲述人类从地球出发、跨越太空、抵达火星并首次踏上火星表面的探索故事。

页面应包含任务背景、前往火星的旅程、火星环境、登陆过程、宇航员探索以及人类未来火星探索的展望。

要求内容完整、具有故事性和沉浸感，让用户能够感受到太空探索的未知、壮阔与人类探索精神。

请自行决定页面的视觉风格、布局、配色、图片、字体、交互方式和具体内容呈现形式。

最终生成一个完整、响应式、可独立运行的前端单页网站，不需要登录、后端、数据库或外部 API。

## Bad Reason

- 首屏的地球、火星和飞船，以及后面的峡谷与着陆场，主要用渐变圆形、几何轮廓和三角形山体表现。插画风格本身可以成立，但这些场景的地形、材质与光影都较简化，整体更像太空科普插画，难以撑起首次登陆需要的壮阔与临场感。手机端首屏背景的居中裁切又让两侧的大行星落到画面之外；相比之下，Good 在桌面和手机上都保留了宇航员与辽阔荒原的对照。
- 排版和信息密度削弱了阅读节奏。首屏同时出现任务档案标签、中英标题、任务参数和滚动遥测条，后文又连续铺开地形卡、着陆卡、人物卡、首次活动记录和多篇完整日志，视觉结构变化有限。1440px 桌面宽度下，“它不荒凉，它只是沉默”还把最后一个“默”字挤成单独一行。Good 的标题层级更清楚，并用可切换的航程日志和折叠记录控制默认阅读篇幅。
- 任务档案存在多处内部矛盾，打断故事的可信感。首屏写四人任务，航行卡片却出现“6 人 · 486 天总任务”，结尾又写总历时 563 天；着陆段写三人下降、一人留守轨道，后面却让四人一起在火星远足。页面还先强调脚印会“永远留在那里”，随后又写风暴把脚印“全抹平了”。内容虽然丰富，却没有形成前后一致的任务故事。
- 登陆段强调“任务真实时序重演”和 `LIVE`，实际却把 420 秒压缩为约 14 秒，并在进入视口后自动播放，没有暂停、手动选择阶段或重播入口。用户难以按自己的节奏理解这个故事的高潮。虽然页脚有虚构声明，局部的“真实时序”标签仍与演示方式不符；Good 提供播放、暂停、继续、重播和阶段选择，并明确注明播放时长不代表真实下降时长。
- 离线交付的视觉稳定性不足。页面通过 Google Fonts 加载 Orbitron、Noto Sans SC 和 Noto Serif SC，断网后内容仍可阅读，但字体会回退，依赖字体形态的标题和档案标签可能改变外观。Good 的 CSS、JS、图片与图标均已内嵌，并使用系统字体，单个 HTML 文件就能保留完整页面与交互。
