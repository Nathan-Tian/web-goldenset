# Golden Set 第 1 组：The Midnight Mystery

## Prompt

Create a complete single-page website for a fictional detective story titled **“The Midnight Mystery.”**

### Goal

Present the story as an immersive visual storytelling experience rather than a plain text article.

### Required Content

Include a hero section, story synopsis, at least six chapters or scenes, major character introductions, visual content for important scenes, a final resolution section, and a footer.

### Design Requirements

The page should have clear visual hierarchy, strong readability, thoughtful spacing, consistent visual language, and enough variation between sections to keep a long scrolling experience engaging.

The final result should feel like a polished production website rather than a collection of disconnected components.

### Technical Constraints

Build it as a standalone responsive frontend webpage. Do not require login, backend services, databases, or external API requests.

### Design Freedom

You may freely decide the visual style, layout, typography, color palette, imagery, and component design.

## Bad Reason

- 七个章节反复使用"文字栏 + 右侧小幅暗色插画"的同构版式，插画尺寸与构图变化很小，长距离滚动缺少起伏。
- 场景插画以 CSS/SVG 几何为主，夜色、雨、钟楼的意图能读出，但缺少材质与空间纵深，
  难以支撑"沉浸式视觉叙事"的定位，图片更多是正文配图而非叙事主体。
- 正文密度高、字号偏小，且长期处于近黑底金字，阅读负担随篇幅累积。
