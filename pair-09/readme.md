# Golden Set 第 9 组：未来感 AI 智能眼镜新品发布

## Prompt

请制作一个以 **未来感 AI 智能眼镜新品发布** 为主题的单页产品网站。

这是一款面向未来日常生活的 AI 眼镜，能够通过人工智能帮助用户获取信息、识别环境、进行实时翻译、语音交互和日常辅助。

页面需要包含：

- 产品首屏与核心卖点
- AI 眼镜的主要功能
- 典型使用场景
- 产品设计与佩戴体验
- AI 能力与交互方式
- 产品参数或核心配置
- 最后的购买或了解更多引导

要求页面具有完整的新品发布感和产品展示逻辑，让用户能够快速理解这款 AI 眼镜的价值和特点。

请自行决定视觉风格、布局、配色、字体、图片、交互方式和内容呈现形式。

不要制作成普通 SaaS 官网或单纯的功能卡片集合。

最终生成一个完整、响应式、可独立运行的前端单页网站，不需要登录、后端、数据库或外部 API。

---

## Golden Set 标注

- **Good：** [AURA ONE](https://nathan-tian.github.io/web-goldenset/pair-09/good/)
- **Bad：** [Lumina One · 灵眸 One](https://nathan-tian.github.io/web-goldenset/pair-09/bad/)

综合判断：Good 更好看，也更值得作为本次前端概念发布页交付。产品大图、留白和文字层级更清楚，AI 视野演示、设计热点与配置探索把产品价值串成了完整体验，移动端信息保留也更完整。

两版都覆盖了提示词要求的主要内容，均可单文件独立运行；Bad 的科幻氛围和五组图文场景也有优点。这里的差距主要是视觉表达与交付完成度，不是 Bad 没有功能或场景，也不是深色风格本身不符合任务。

## Bad Reason

- 首屏大标题和说明直接叠在眼镜主图上，文字与产品细节互相抢画面；灰色细字落在发光背景上，对比不足，核心卖点不够易读。
- 编号、英文小标题、长段说明和大段间距反复出现，功能与场景章节的呈现节奏较单一，读起来更像长篇宣传介绍，缺少精炼的产品展示节奏。
- 设计与佩戴区主要复用侧脸人像，镜框材质、铰链和感知模组等部件缺少清晰的细节展示，不如 Good 的产品特写与可点击热点直观。
- 手机端参数表直接隐藏显示屏、摄像头、续航等右半部分信息，剩余单元格仍被限制为窄列，出现大量逐字换行，没有完成可靠的响应式适配。
- 预约区宣称填写后生效并会短信通知，成功提示又称信息保存在本地；实际只切换提示、清空输入并禁用按钮，没有保存或发送信息。问题不在于缺少后端，而是演示反馈与实际行为不一致，不宜直接交付。
