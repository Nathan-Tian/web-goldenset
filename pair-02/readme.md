# Golden Set 第 2 组：72 Hours in Kyoto

## Prompt

Create a complete visual travel guide titled **“72 Hours in Kyoto.”**

### Goal

Help a visitor understand how to spend three memorable days in Kyoto through a visually rich and easy-to-follow webpage.

### Required Content

Include a strong introduction, a three-day itinerary, important landmarks, food recommendations, cultural experiences, practical travel tips, visual content for major destinations, and a closing section.

### Design Requirements

The page should balance editorial content and imagery, establish clear visual hierarchy, maintain comfortable reading density, and create a coherent travel experience across the full page.

### Technical Constraints

Build it as a responsive standalone frontend webpage without backend services, authentication, databases, or external API requests.

### Design Freedom

Choose the visual style, layout system, imagery, typography, colors, and components freely.

## Bad Reason

- 三天行程都采用相似的“时间轴 + 大段文字 + 插画”结构，长距离滚动时节奏较重复，缺少足够明确的内容收放。
- 信息密度偏高，同时展示步行里程、景点数量、价格、时长和大量补充路线，新访客较难迅速判断每天真正应该优先完成的事项。
- 主要目的地以代码插画表现，风格统一但对真实场所的辨识帮助有限，作为面向实际游客的视觉指南，不如实景摄影直观。
- 部分文案带有较强的宣传与虚构表达，并包含容易变化的价格、交通和开放时间信息；页面末尾又声明内容为 fictional travel concept，削弱了实际交付时的可信度。
- 相比之下，Good 版本以真实目的地摄影、清晰的三日分区、克制的文字密度和明确的地标、饮食、文化及实用提示结构，更符合“visually rich and easy-to-follow”的目标。
