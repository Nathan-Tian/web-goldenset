# Golden Set 第 8 组：泰坦尼克号最后一夜

## Prompt

请制作一个以 **“泰坦尼克号最后一夜”** 为主题的单页故事网站。

页面围绕泰坦尼克号撞上冰山到最终沉没前的最后几个小时展开，通过时间推进讲述船上乘客、船员、救援与灾难发生的过程。

内容可以包含：

- 泰坦尼克号航行背景
- 撞上冰山前的夜晚
- 冰山碰撞
- 船上逐渐出现的混乱
- 救生艇撤离
- 不同人物在灾难中的选择
- 泰坦尼克号最终沉没
- 事件后的纪念与反思

要求页面具有完整的故事性和时间推进感，让用户能够感受到这场历史事件中的震撼、悲剧和人性。

请自行决定视觉风格、布局、配色、图片、字体、交互方式和内容呈现形式。

不要制作成普通历史百科或资料介绍页。

最终生成一个完整、响应式、可独立运行并且精致的前端单页网站，不需要后端、登录、数据库或外部 API。

## Bad Reason

- 深蓝背景、金色大字和星点装饰营造了夜航氛围，但大字号标题与巨轮画面争抢注意力，文字断行、间距和留白不够讲究。整体更像常见的暗色宣传长页，缺少构图与排版打磨后应有的精致感和高级感。
- 配图在大面积暗色遮罩下，船体、海面和人物的细节不够鲜明，画面的光影与空间层次较弱。向下浏览时，图片与文字仍是一块块铺开，更像在翻阅配图文章，难以产生站在甲板上、置身冰冷海面的临场感。
- 插图带有较明显的现代数字绘画质感，页面缺少旧照片、纸张肌理、船票与电报纸等时代细节的呼应。虽然能辨认出泰坦尼克号的题材，却难以从视觉上感受到 1912 年的生活气息，缺少回到那个年代的历史感。
