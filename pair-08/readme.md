# Golden Set 第 8 组：泰坦尼克号最后一夜

## Prompt

请制作一个以 **“泰坦尼克号最后一夜”** 为主题的单页故事网站。

页面围绕泰坦尼克号撞上冰山到最终沉没前的最后几个小时展开，通过时间推进讲述船上乘客、船员、救援与灾难发生的过程。

内容可以包含：

- 泰坦尼克号航行背景
- 撞上冰山前的夜晚
- 冰山碰撞
- 船上逐渐出现的混乱
- 救生艇撤离
- 不同人物在灾难中的选择
- 泰坦尼克号最终沉没
- 事件后的纪念与反思

要求页面具有完整的故事性和时间推进感，让用户能够感受到这场历史事件中的震撼、悲剧和人性。

请自行决定视觉风格、布局、配色、图片、字体、交互方式和内容呈现形式。

不要制作成普通历史百科或资料介绍页。

最终生成一个完整、响应式、可独立运行并且精致的前端单页网站，不需要后端、登录、数据库或外部 API。

## Golden Set 标注

- **Good：** https://nathan-tian.github.io/web-goldenset/pair-08/good/
- **Bad：** https://nathan-tian.github.io/web-goldenset/pair-08/bad/


## Bad Reason

- 首屏标题字号与断行缺少控制，“最后一夜”的“夜”在桌面端被单独挤到下一行；手机端的品牌文字和目录按钮也出现拥挤换行。标题与巨轮画面的关系不够协调，削弱了历史叙事开场应有的完整感。
- 大面积深蓝背景、重复的图文段落和连续八组人物介绍，使后半段的阅读节奏较单一。人物主要通过姓名、身份和长段文字呈现，更像历史资料列表，弱化了灾难中具体人物与选择的情绪感染力。
- 时间信息存在前后矛盾：跨过午夜后顶部日期仍停留在“APR 14”，碰撞到沉没的两小时四十分钟又被写成“两小时二十分钟”。这类细节会打断时间推进的体验，也影响历史故事的可信度。
