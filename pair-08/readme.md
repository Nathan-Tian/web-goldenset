# Golden Set 第 8 组：泰坦尼克号最后一夜

## Prompt

请制作一个以 **“泰坦尼克号最后一夜”** 为主题的单页故事网站。

页面围绕泰坦尼克号撞上冰山到最终沉没前的最后几个小时展开，通过时间推进讲述船上乘客、船员、救援与灾难发生的过程。

内容可以包含：

- 泰坦尼克号航行背景
- 撞上冰山前的夜晚
- 冰山碰撞
- 船上逐渐出现的混乱
- 救生艇撤离
- 不同人物在灾难中的选择
- 泰坦尼克号最终沉没
- 事件后的纪念与反思

要求页面具有完整的故事性和时间推进感，让用户能够感受到这场历史事件中的震撼、悲剧和人性。

请自行决定视觉风格、布局、配色、图片、字体、交互方式和内容呈现形式。

不要制作成普通历史百科或资料介绍页。

最终生成一个完整、响应式、可独立运行并且精致的前端单页网站，不需要后端、登录、数据库或外部 API。

## Golden Set 标注

- **Good：** [查看页面](https://nathan-tian.github.io/web-goldenset/pair-08/good/)
- **Bad：** [查看页面](https://nathan-tian.github.io/web-goldenset/pair-08/bad/)

**交付建议：选择 Good。** Good 的巨轮首屏、克制的标题排版、深海蓝与旧纸色的章节转换，更有完整作品的质感。持续可见的时间轴把碰撞、撤离、沉没与黎明串起来；历史照片与艺术复原区分明确，人物切换、照片放大和最后的纪念交互也服务于故事。Bad 的灾难场景插画更多，事件铺陈更详细，具备明显的夜航氛围，但版式细节、阅读节奏和时间表述的一致性不如 Good，更接近一篇配有插画的长篇历史专题。

两版均已将 CSS、JavaScript、图片与字体内嵌，可作为单个 HTML 独立运行。本次比较检查了 1280px 桌面视口与 390px 手机视口，以及章节导航、Good 的人物切换和图片放大。Good 的部分辅助说明仍偏小、偏淡，后续可进一步改善可读性。

## Bad Reason

- 标题与导航的排版收尾不够精细。在 1280px 桌面视口下，首屏标题把“最后一夜”的“夜”单独挤到下一行，标题分组和巨轮构图受到破坏；在 390px 手机视口下，顶部品牌文字换成两行，“目录”按钮也被挤成上下两字。页面仍可使用，但这些细节削弱了提示词要求的精致感。
- 内容丰富，但后半段的阅读节奏偏向资料罗列。人物章节连续列出八组人物或群体，主要采用相似的姓名、身份和长段说明；与前面的灾难场景相比，视觉叙事明显减弱。Good 用照片、三组可切换的人物故事和较短的叙述，让读者更容易把注意力留在具体的人与选择上。
- 时间导航没有完整处理跨越午夜的过程。顶部时钟会随章节变化，日期却固定显示“APR 14”；到 4 月 15 日凌晨的救援章节，仍显示“APR 14 04:10”。这与页面正文的日期冲突，也削弱了本题最重要的时间推进感。
- 文案存在可以直接从页面内部核对出的矛盾。序章写“第十一天前，她离开南安普顿”，但正文给出的启航日期是 4 月 10 日，主题之夜是 4 月 14 日，两者相隔四天；人物章节末尾又写“两小时二十分钟”，与页面标出的 23:40 撞击、次日 02:20 沉没相差两小时四十分钟不符。这些问题会影响历史叙事的交付可信度。
