# Golden Set 第 3 组：山水林州

## Prompt

请为中国河南省林州市制作一个**单页宣传网页**，面向国内用户，整体风格要有品质感、沉浸感和地域特色，不要做成普通的信息堆砌式旅游官网，也不要像政府公告页面。  \
&#x20;页面定位\
&#x20;这是一个展示林州城市形象的宣传页，核心主题是：\
&#x20; \
&#x20;**“山水林州，太行气魄，红旗渠精神。”**\
&#x20; \
&#x20;希望用户看完后，能感受到林州不仅有壮美的自然风光，还有深厚的人文底蕴和鲜明的城市精神。  \
&#x20;页面内容要求\
&#x20;页面至少包含以下部分：  

1. **首屏 Hero**
   - 大幅视觉展示林州代表性风光，如太行山、太行大峡谷等
   - 主标题可用：**山水林州**
   - 副标题可用：**一座生长在太行山下的城市**
   - 首屏要有视觉冲击力，简洁大气，不要堆太多按钮和卡片
2. **林州简介**
   - 简要介绍林州的地理位置、城市特色和整体气质
   - 强调林州与太行山之间的联系
3. **太行山与自然风光**
   - 展示太行山、峡谷、山路、云海、日出等景观
   - 突出林州山城特色，画面要有层次感和沉浸感
4. **红旗渠专题**
   - 重点介绍红旗渠
   - 不只把它当作景点，更要突出其背后的奋斗精神和林州人民的坚韧品质
   - 这一部分应成为整页的重要亮点
5. **石板岩与山间生活**
   - 展示石板岩、村落、石头房屋、街巷、日常生活气息
   - 氛围比前面更温暖、更有人情味
6. **林州四季**
   - 展现春夏秋冬不同景色
   - 不要简单做成四个完全重复的小卡片，版式要有变化
7. **美食与人文**
   - 介绍林州本地美食、生活方式、地方文化
   - 强调“有风景，也有烟火气”
8. **结尾总结**
   - 用一句有感染力的话收尾，例如：\
     &#x20;**“山塑造了林州，林州人也改变了山。”**
   - 配合大幅山景或城市画面，形成有记忆点的结束

设计要求

- 整体风格：**高级、沉浸、简洁、大气、有文化感**
- 视觉气质：偏纪录片感、城市品牌宣传感，而不是普通旅游信息页
- 主色调可采用：山石灰、森林绿、暖土色、云雾白，并用少量红色点缀呼应红旗渠精神
- 页面要有清晰的信息层级、舒适留白、统一视觉语言
- 不要过度使用圆角卡片、花哨渐变、通用 SaaS 风格组件
- 不要让每个 section 都长得一样，要有节奏变化

交互与技术要求

- 做成一个**完整的响应式单页网页**
- 适配桌面端和移动端
- 可以加入适度的滚动动画、视差、淡入等效果，但不要过多炫技
- 不需要登录、后端、数据库、外部 API 请求
- 最终页面应是一个可独立运行的前端网页

最终效果目标\
&#x20;请把这个页面做得像一个**真正用来宣传林州城市形象的高质量专题网页**，让用户看完后记住林州的山、林州的水、林州的红旗渠，也记住这座城市的精神气质。

## Bad Reason

- 首屏虽然通过巨型中文字体、暗色调和抽象山体营造了鲜明的展览感，但缺少真实林州风光，地域辨识度和城市宣传片式的视觉冲击力不足。
- 页面主要依赖 CSS 图形、纹理和文字完成表达，几乎没有实景影像，未充分满足提示词对太行山、峡谷、山路、云海、村落、四季和结尾大幅山景的明确要求。
- 红旗渠段落的历史叙述较完整，口号式标题也有力量，但没有以人物、渠体和太行绝壁等画面支撑，难以把“奋斗精神”转化为更具体、更具感染力的视觉记忆。
- 石板岩、四季与美食部分仍以抽象色块和文字为主，山间生活的温度、村落日常和“有风景，也有烟火气”的氛围没有真正呈现出来。
- 大字号标题与较小、较低对比度的正文形成较强反差，长距离阅读更接近艺术展览长文，对面向大众的城市形象宣传页而言可读性和亲和力偏弱。
- 相比之下，Good 版本以真实山水摄影为主线，首屏、红旗渠、石板岩、四季和结尾之间有明确的视觉节奏与色彩变化，在桌面端和移动端都更接近可直接交付的高质量城市品牌专题页。
